# 词间 · 六级词汇测验

面向手机浏览器的个人词汇测验工具，免注册。非刘晓艳老师或课程官方产品。

## 功能

- 按 Lesson 选择词义、拼写、混合测验，各题组独立保存进度。
- 选项点击即判分，错词自动进入薄弱词本；收藏由用户手动选择。
- 斩词、10 秒撤销、恢复及主动抽查，默认排除已斩词。
- 按词义和拼写分别安排 1、3、7、14、28 天复习；这是一组产品默认间隔，不是个人记忆能力的精确预测。
- 每日复习预算默认 30 分钟；暂停、后台不计时。
- 本地保存，JSON 导出与合并导入。不同网址和设备不会自动同步。
- 新用户从第一课开始；设置中可批量登记学习进度。

## 当前范围与限制

题库为 2179 个核心词、1158 条去重后的延伸词，共 40 课。其中 872 条延伸词可测，286 条待核对记录仅供查看、不出题。已合并英美拼写变体。覆盖 PDF 10–292 页；293 页起基础词表及索引不在本次交接范围。详见 data/import-audit.json。未对所有扫描页逐页独立复核。暂不提供系统提醒或跨设备同步。已支持匿名使用统计及作者管理页。

词条顺序、课程和释义整理自用户提供的学习材料；内容授权尚未获得独立确认，不提供源 PDF、课件或课程故事。当前仓库未授予词表内容再分发许可。若需推广到公开学习社区，应先确认内容授权，或替换为有明确开放许可的词表。纠错及权利问题请通过 Issues 联系。

## 开发

Node.js 24（测试使用 node:sqlite）；部署代码运行于 Cloudflare Workers：

```sh
npm ci
npm test
npm run build
npm start
```

开发预览运行 npm run dev，使用终端打印的地址。本地需按 Sites starter 流程应用 drizzle/ 中的迁移。 .dev.vars 中仅配置本地测试用 ANALYTICS_SALT 和 CIJIAN_OWNER_EMAIL，勿提交。

web/ 是测验与管理页源代码；server/ 和 app/api/ 是统计服务；db/ 与 drizzle/ 管理迁移。Sites/Vinext 构建服务端产物。单文件测验仍可离线使用，但统计需要同源服务端，不依赖模型 API。

## 隐私与备份

学习记录继续保存在本机，不上传具体单词、答案或错词。默认匿名上报访问、作答、完成事件及首次链接来源，设备随机ID在服务端以HMAC摘要保存；不主动采集IP或邮箱。设置中可关闭后续统计，历史数据保留。自动化浏览器默认不报；作者登录状态不报；打开管理页会排除该浏览器历史测试数据。更换浏览器或清理数据会造成设备重复计数，离线和拦截会漏计，不能等同于实际人数。

## 发布

公开站点由 Sites 托管。GitHub 保存源码，GitHub push 当前不会自动更新 Sites；上线必须重新构建并发布。当前公开版依赖 Sites D1 和身份头。CIJIAN_OWNER_EMAIL 限定管理账号，ANALYTICS_SALT 为服务端秘密；均通过托管环境配置，不写入源码。

## 验证

npm test 检查斩词的队列与历史保留规则。浏览器验证覆盖按课测验、直接判分、错词、收藏、斩词与恢复以及刷新保存。tests/ 中 *.qa.js 为 Playwright CLI 的浏览器检查函数，需要先打开干净的测试页面，不应在真实学习记录中运行。

## 统计入口与口径

/admin 仅作者登录可读，/api/stats 对匿名返回401、其他账号403。页面显示累计访问设备、完成测验设备、近7天作答设备、第7天精确回访率、来源和30日明细，支持CSV导出。第7天回访分母仅含首次完成测验已满7天的设备，分子为恰好第7个自然日作答者；按北京时间。事件ID去重，单设备每天最多102条，无法完全防止人为造量。统计从上线起记录，历史不可补算。
