# 词间 · 六级词汇测验

面向手机浏览器的个人词汇测验工具，免注册。非刘晓艳老师或课程官方产品。

## 功能

- 按 Lesson 选择词义、拼写、混合测验，各题组独立保存进度。
- 选项点击即判分，错词自动进入薄弱词本；收藏由用户手动选择。
- 斩词、10 秒撤销、恢复及主动抽查，默认排除已斩词。
- 按词义和拼写分别安排 1、3、7、14、28 天复习；这是一组产品默认间隔，不是个人记忆能力的精确预测。
- 每日复习预算默认 30 分钟；暂停、后台不计时。
- 本地保存，JSON 导出与合并导入。不同网址和设备不会自动同步。
- 新用户从第一课开始；设置中可批量登记学习进度。

## 当前范围与限制

试用题库为 887 个核心词、18 课，不是全书。扩展词尚未上线。暂不提供系统提醒、跨设备同步或用户量统计。

词条顺序、课程和释义整理自用户提供的学习材料；内容授权尚未获得独立确认，不提供源 PDF、课件或课程故事。当前仓库未授予词表内容再分发许可。若需推广到公开学习社区，应先确认内容授权，或替换为有明确开放许可的词表。纠错及权利问题请通过 Issues 联系。

## 开发

Node.js 20 或更新版本：

```sh
npm ci
npm test
npm run build
npm start
```

打开 http://127.0.0.1:5181/ 。也可以直接打开 dist/index.html；HTTP 环境的本地存储兼容性更好。

web/ 是源代码，dist/index.html 是可独立运行的成品，不依赖模型 API 或服务端。构建只使用 esbuild；不依赖其他本地项目。scripts/ 中不包含原型阶段的一次性修改脚本。

## 隐私与备份

此版本不主动上传作答记录，不创建账号。托管平台可能生成普通访问日志。浏览器清理数据、无痕模式结束或更换网址可能导致记录丢失，请定期导出备份。若未来加入匿名统计，应单独说明字段、口径和退出方式。

## 发布

公开站点由 Sites 托管。GitHub 保存源码，GitHub push 当前不会自动更新 Sites；上线必须重新构建并发布。静态成品也可部署到其他支持 HTTPS 的静态托管服务。

## 验证

npm test 检查斩词的队列与历史保留规则。浏览器验证覆盖按课测验、直接判分、错词、收藏、斩词与恢复以及刷新保存。tests/ 中 *.qa.js 为 Playwright CLI 的浏览器检查函数，需要先打开干净的测试页面，不应在真实学习记录中运行。
